# 演示截图占位目录

本目录用于存放**演示截图**。README 中已经用与文件名一致的引用指向这里：

| 文件名 | 对应环节 | 截图建议 |
| --- | --- | --- |
| `step1-data-retrieval.png` | 第一步：真实数据获取与样本分组 | 终端里"样本分组（依据平台真实互动数据）"对比表 + 数据溯源提示 |
| `step2-analysis.png` | 第二步：六维拆解与差异归因 | 六维拆解对比表 + 关键变量归因表 + 核心洞察 + 解释力自评 + 模板沉淀 |
| `step3-human-gate.png` | 第三步：人工确认暂停框 | 黄色 `HUMAN-IN-THE-LOOP` 暂停框 + 《二创内容确认单》 |
| `step4-asset-logged.png` | 第四步：资产入库日志 | "内容已入库，ID: ASSET-xxxx，待后续追踪表现。"的绿色日志 |

## 如何生成这些截图

```bash
# 运行离线 Demo（使用内置真实抓取快照，无需联网/Key）
python demo.py --offline
```

按上面四个节点在终端截屏，保存到本目录，文件名与表格一致即可。
CI 不会校验这些图片是否存在，它们仅用于 README 展示。
